# Forks

Divergences, each with its commitment diff.

Per §8.6 of the paper, a fork is a new repository state that differs from its parent in at least one commitment. Three kinds must not be confused:

| Type | What changes | Status |
|---|---|---|
| Commitment fork | a constitutive commitment | genuine philosophical disagreement |
| Encoding fork | the translation of the same commitment | dispute about translation; settled by proponent audit |
| Parameter fork | non-constitutive settings or environment | engineering variation |
